# KEYBINDS MAKIMA - RESUMEN

## Principales (Caelestia + Hypr)
| Acción | Tecla |
|--------|-------|
| Launcher | `SUPER + Space` |
| Terminal (kitty) | `SUPER + Return` |
| Browser (firefox) | `SUPER + W` |
| Editor (gnome-text-editor) | `SUPER + T` |
| Files (dolphin) | `SUPER + E` |
| Calc | `SUPER + C` |
| Lock | `SUPER + L` |
| Mute | `SUPER + SHIFT + M` |
| Monitor siguiente | `SUPER + SHIFT + N` |
| Monitor 1/2/3 (físico) | `SUPER + SHIFT + 1/2/3` |
| Minimizar (scratchpad) | `SUPER + H` |
| Restaurar | `SUPER + SHIFT + H` |
| Zoom | `SUPER + ±` |
| Screenshot región | `SUPER + SHIFT + S` |
| Screenshot full | `Print` |
| Btop | `CTRL + SHIFT + Esc` |
| App switcher visual | `ALT + TAB` |

## Archivos modificados:
- ~/.config/caelestia/hypr-vars.lua (apps, binds, gaps, blur)
- ~/.config/caelestia/hypr-user.lua (workspaces code:, zoom, calc, btop, monitor)
- ~/.config/caelestia/shell.json (tema Makima, autoHide, statusIcons)
- ~/.config/hypr/hyprland/rules.lua (fullscreen opaque, gaps)
- ~/.config/hypr/hyprland/input.lua (kb_layout=latam)
